# Contributing to CODE.X

Thank you for your interest in contributing to CODE.X! 🚀

CODE.X is an open-source AI-powered code understanding project. We welcome contributions from developers, students, and the open-source community.

## How to Contribute

### 1. Fork the Repository

Fork the CODE.X repository to your GitHub account.

### 2. Clone Your Fork

```bash
git clone https://github.com/sigmaboy143/CODE.X.git
cd CODE.X
```

### 3. Create a Branch

Create a separate branch for your changes:

```bash
git checkout -b feature/your-feature-name
```

For bug fixes:

```bash
git checkout -b fix/your-bug-name
```

### 4. Make Your Changes

Implement your feature, improvement, or bug fix.

Please keep your changes focused and avoid unrelated modifications.

### 5. Test Your Changes

Make sure your changes work correctly and do not break existing functionality.

### 6. Commit Your Changes

Use a clear commit message:

```bash
git add .
git commit -m "Add: your change description"
```

### 7. Push Your Branch

```bash
git push origin feature/your-feature-name
```

### 8. Open a Pull Request

Open a Pull Request from your branch to the `main` branch.

Clearly describe:

- What you changed
- Why you made the change
- How you tested it
- Any relevant screenshots or examples

## Contribution Guidelines

- Write clear and maintainable code.
- Follow the existing project structure and coding style.
- Test your changes before submitting a Pull Request.
- Do not commit API keys, passwords, tokens, or other secrets.
- Keep Pull Requests focused on a single feature or fix.
- Be respectful and constructive when communicating with other contributors.

## Reporting Bugs

If you find a bug, open a GitHub Issue and include:

- A clear description of the problem
- Steps to reproduce it
- Expected behavior
- Actual behavior
- Relevant logs or screenshots
- Environment information when applicable

## Suggesting Features

Feature suggestions are welcome.

Before opening a feature request, check whether a similar issue already exists.

Explain:

- The problem you want to solve
- Your proposed solution
- Why the feature would be useful

## Code of Conduct

By participating in this project, you agree to communicate respectfully and help maintain a welcoming open-source community.

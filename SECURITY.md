# Security Policy

## Supported Versions

CODE.X is currently under active development.

Security fixes will be applied to the latest actively maintained version of the project.

## Reporting a Security Vulnerability

If you discover a security vulnerability in CODE.X, please do not publicly disclose the vulnerability through a GitHub issue.

Instead, report it privately to the project maintainers through GitHub's private security reporting features, if enabled.

Please include:

- A clear description of the vulnerability
- Steps to reproduce the issue
- Potential impact
- Relevant screenshots, logs, or proof of concept
- Any suggested mitigation, if available

## What Not to Include

Please do not include sensitive information such as:

- API keys
- Passwords
- Authentication tokens
- Private credentials
- Personal information

in public issues, pull requests, or discussions.

## Responsible Disclosure

We appreciate responsible security research and will make reasonable efforts to investigate and address valid security reports.

Thank you for helping keep CODE.X and its users secure.
